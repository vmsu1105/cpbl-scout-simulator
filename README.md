# ⚾ 台灣職棒・球探模擬器 (CPBL Scout & GM Simulator)

> **400 人深度母庫・五年王朝・首席球探兼總管養成大作**  
> 一款專為台灣棒球迷打造的純前端文字與數據策略經營模擬遊戲。

---

## 🌟 遊戲特色

1. **400 位深度選秀母庫**
   - **42 位 殿堂級神獸**：徐若熙、王建民、陳金鋒、張育成、江坤宇、李灝宇、陳冠宇、吳念庭等，具備主宰聯盟之頂級天賦。
   - **172 位 中流砥柱**：各隊建隊基石、穩定攻守核心（胡金龍、林岳平、高志綱等）。
   - **86 位 致命地雷**：隱蔽機制缺陷、傷病隱患，考驗球探火眼金睛。
   - **100 位 實用普通人**：低調穩健公務員，鞏固板凳深度。
   - **海歸大物隨機返台**：旅美、旅日名將動態返台投入選秀。

2. **真實硬核賽季模擬引擎**
   - **空間擠壓機制（Roster Crunch Squeeze）**：前 4 高新秀全額計入 WAR，第 5 名以後擔任替補（50% 折算），徹底重現一軍席位排擠。
   - **零和賽季運氣（Zero-Sum League Luck）**：全聯盟 6 隊運氣嚴格歸零（±3 場一分差波動），有人走運必有人倒楣，120 場賽制嚴格 360 勝閉環。
   - **球團老將底蘊長效保留**：各隊原生體質長年平滑發揮影響力，新秀戰力與老將陣容完美平衡。

3. **五年任期制度與考評評價**
   - 執掌南方雄鷹、北方王者、天空龍、南霸天猛獅、暴力狂猿或黃衫大象。
   - 五年任期屆滿依據勝場、冠軍座數、神獸培育度結算專屬考評等級（`SS` 傳奇鷹眼、`S` 金牌球探、`A` 中流砥柱、`F` 地雷磁鐵）。

4. **📸 一鍵高畫質戰報截圖分享**
   - 內建 `html2canvas` 高解析 2x Retina 渲染引擎。
   - 專為社群（PTT、Threads、Dcard、LINE、Discord）打造的官方認證考評戰報卡，支援一鍵下載 PNG 與複製至剪貼簿！

## 🚀 本地啟動與開發

本遊戲為純前端靜態網頁（Vanilla HTML5 / JavaScript / Tailwind CSS），無需任何後端伺服器或資料庫：

```bash
# 使用任意靜態 HTTP 伺服器啟動（如 Python）
python -m http.server 3000

# 瀏覽器打開
http://localhost:3000
```
